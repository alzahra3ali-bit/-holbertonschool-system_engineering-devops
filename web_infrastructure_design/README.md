# Web Infrastructure Design

This repository contains architecture designs, whiteboard diagrams, and explanations for various web infrastructures, ranging from simple single-server setups to secure, monitored, and distributed systems.

## Projects Covered
- **0-simple_web_stack**: Basic LAMP stack on a single server (SPOF analysis).
- **1-distributed_web_infrastructure**: Scaling with load balancers and database replication.
- **2-secured_and_monitored_web_infrastructure**: Adding firewalls, SSL/HTTPS, and monitoring tools.
